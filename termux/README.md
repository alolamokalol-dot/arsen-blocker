# Запуск пульта одной командой в Termux

Цель: после установки Termux управлять ПК короткой командой `arsen`, не набирая путь к Python-файлу каждый раз.

## Один раз установить

1. Установите Termux из F-Droid.
2. Разархивируйте `arsen_blocker.zip` на телефоне или скопируйте папки `termux` и `python` в одну общую папку телефона.
3. Откройте Termux и выполните:

```bash
pkg update -y
pkg install python -y
termux-setup-storage
```

4. Перейдите в папку `termux` и запустите:

```bash
bash setup.sh
```

Если `client_tui.py` лежит в соседней папке `python`, установщик найдёт его сам. Можно также положить `client_tui.py` прямо рядом с `setup.sh`.

## Каждый следующий раз

Просто введите:

```bash
arsen
```

При первом запуске введите IP ПК, порт `9099` и токен — дальше настройки сохраняются.

Короткие команды:

```bash
arsen ping
arsen users
arsen block ИМЯ_ПОЛЬЗОВАТЕЛЯ 30
arsen unblock ИМЯ_ПОЛЬЗОВАТЕЛЯ
arsen status
```

Обычное меню безопаснее для блокировки администратора: оно попросит отдельное подтверждение.
