# Однокнопочный `ArsenBlockerSetup.exe`

Да, файлы можно упаковать в один EXE. Здесь используется **PS2EXE**: он встраивает два PowerShell-файла внутрь Windows-программы. EXE при запуске извлекает их во временную папку, поднимает обычный установщик от администратора, тот размещает агента в `C:\ProgramData\ArsenBlocker` и создаёт задачу автозапуска.

## Важное различие

- **Собирать EXE будет один раз сборщик** на Windows-компьютере с интернетом. После этого готовый `ArsenBlockerSetup.exe` можно передать Арсену — на целевом ПК PowerShell-консоль и ручной ввод команд уже не нужны.
- Для сборки нужен PowerShell 5.1 (он входит в Windows) и интернет, чтобы установить официальный модуль `ps2exe` из PowerShell Gallery.
- Запуск Setup.exe покажет стандартное окно Windows UAC: без согласия на админ-права ОС не разрешит установить автозадачу от `SYSTEM` и настроить брандмауэр. Это штатный запрос безопасности.
- В этой поставке готовый EXE **не приложен**: среда подготовки — Linux, не Windows. Подготовлен проверяемый сборщик; выдавать не собранный и не протестированный Windows-бинарник за готовый было бы неправильно.

## Сборка (один раз на Windows)

1. Распакуйте проект целиком, так, чтобы папки `windows`, `python`, `android` и `tests` сохранили свою структуру.
2. Откройте **Windows PowerShell** (не обязательно от администратора для сборки).
3. Перейдите в папку проекта, например:

   ```powershell
   cd C:\Users\Arsen\Downloads\arsen_blocker
   ```

4. Если Windows запрещает запуск локальных скриптов в этом окне, разрешите только текущему процессу PowerShell:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass -Force
   ```

5. Запустите сборку:

   ```powershell
   .\windows\build_setup_exe.ps1
   ```

6. Готовый файл появится здесь:

   ```text
   dist\ArsenBlockerSetup.exe
   ```

Сборщик самостоятельно установит модуль `ps2exe` для текущего пользователя, соберёт EXE, встроит файлы `block_agent.ps1` и `install_agent.ps1` и включит манифест `requireAdmin`.

## Установка на целевом ПК

1. Передайте на ПК **только** `ArsenBlockerSetup.exe`.
2. Дважды щёлкните по нему.
3. Подтвердите запрос UAC кнопкой «Да».
4. Оставьте открывшееся окно до завершения. В конце оно покажет IP-адрес, порт и токен.
5. Перепишите IP и токен в Termux командой `arsen --setup` или при первом запуске `arsen`.

Настройки будут в `C:\ProgramData\ArsenBlocker\config.json`; при повторном запуске установщика они не стираются.

## Удаление

Сборщик генерирует EXE с вложенными PowerShell-параметрами. Для удаления безопаснее вызвать находящийся в папке проекта установщик:

```powershell
.\windows\install_agent.ps1 -Uninstall
```

Он удалит задачу и правило брандмауэра, но оставит файлы конфигурации и токен. Не удаляйте `C:\ProgramData\ArsenBlocker`, если хотите сохранить настройки.

## Безопасность и ограничения упаковки

- Это упаковка скрипта, **не шифрование и не «невскрываемая» компиляция**. Открытый PS2EXE документирует параметр `-extract:<файл>` для извлечения скрипта; поэтому токен в EXE не зашит и в исходниках не хранится.
- EXE не подписан издательским сертификатом. Windows SmartScreen/Defender может показать предупреждение, особенно если файл передаётся с другого ПК. Не выключайте антивирус ради запуска. Для распространения среди других людей нужен код-подписывающий сертификат и подпись издателя.
- Некоторые антивирусы подозрительно относятся к любым PowerShell-упаковщикам, даже если скрипт безвреден. Если так произойдёт, используйте исходный `install_agent.ps1` и проверьте его содержимое сами.
- В этой системе токен генерируется на первом запуске агента и сохраняется в `config.json`; секретов в собранном EXE нет.
